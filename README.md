# CHEF'S SECRET 🍳

A modern Flutter recipe application with rich recipe discovery, nutritional breakdowns, category browsing, and saved favorite recipes.

**Owner & Author:** Varshitha Ruttala

---

## Features
- Over 5,000+ detailed recipes powered by Spoonacular API
- Ingredient and nutritional breakdown per serving
- Related and similar recipes recommendations
- Auto-complete recipe search
- Bookmark and save favorite recipes locally (Hive storage)
- Random recipe discovery
- Clean, responsive UI with smooth animations

---

## Tech Stack
- **Framework:** Flutter (Dart)
- **State Management:** Flutter BLoC & Cubit pattern
- **Local Storage:** Hive database
- **Networking:** Dio HTTP client
- **API Source:** Spoonacular Food API
